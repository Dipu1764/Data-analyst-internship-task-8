# Data-analyst-internship-task-8

**📊 Superstore Sales Performance Dashboard
📌 Project Overview**

This project focuses on building an interactive Tableau dashboard to analyze sales performance using the Superstore Sales dataset.
The dashboard highlights sales trends over time, regional performance, and category contributions, enabling business users to make data-driven decisions.

**🎯 Objectives**

Import and clean sales dataset

Create interactive visualizations in Tableau

Build a dashboard with filters for deeper analysis

Summarize findings in clear insights

**🛠 Tools Used**

Tableau Desktop (for dashboard design)

Excel / CSV (dataset)

(Optional) Python + Pandas (for initial cleaning)

**📂 Dataset**

File: Superstore_Sales_Clean.csv

Columns Used:

Order Date

Region

Category

Sales

Profit

**📈 Dashboard Contents**

**Line Chart – Sales Over Months**

Displays monthly sales trends

Helps identify seasonality and growth

**Bar Chart – Sales by Region**

Compares sales across regions

Highlights top-performing region

**Pie Chart – Sales by Category**

Shows share of sales by Furniture, Office Supplies, and Technology

Interactive Filters

Region filter

Category filter

**🔑 Key Insights**

Sales peak in Q4, showing seasonality.

The West region has the highest sales performance.

Technology category contributes the largest share of revenue.

**✅ Outcome**

The final dashboard provides a clear and interactive summary of sales performance.
It allows managers and analysts to quickly evaluate trends, compare regions, and understand category contributions.
